# Florr.io Language Pack WASM
A userscript for injecting language packs into Florr by modifying the WASM.

## How to install
 - Install [Tampermonkey](https://chromewebstore.google.com/detail/tampermonkey/dhdgffkkebhmkfjojejmpbldmpobfkfo?hl=en) from the Chrome Web Store.
 - Enable Developer Mode if necessary.
 - Create a new userscript.
 - Paste ```userscripts/index.js``` into the new userscript.
 - Reload Florr.io.

### Note: Florr.io frequently updates its WASM, so you will have to use the latest patch file.
